沙丘语 · 安卓 CyIME 安装说明
========================================

一、装输入法

1. 安装你下载的 CyIME-1.15.107-arm64-v8a.apk（轻量版够用）。
   轻量版少的只是语音、手写、联想这些"模型"，沙丘语用的 lua 是引擎自带的，不受影响。
2. 打开 CyIME，按向导走三步：
   · 在系统里启用 CyIME
   · 准备输入方案（第一次要等几分钟，等它跑完）
   · 把当前输入法切成 CyIME

二、装沙丘语方案

3. 把 沙丘语_手机端_CyIME.zip 传到手机（QQ / 微信「文件传输助手」发给自己最省事）。
   不要解压，直接把这个 zip 拿去导入。
4. CyIME 里进：设置 → 扩展 → 方案 → 右上角「已安装」→「导入方案」
   选中这个 zip。装好后会自动应用，等几秒。
5. 切到沙丘语：
   键盘工具栏 →「输入方式」→ 选「沙丘语·Dune」
   （也可以：设置 → 语言与方案 → 已安装的方案 → 打开「沙丘语·Dune」）

三、试一下

6. 用 26 键打 woele，应该出来：
   咯嗯... 沙—丘 饿—饿...
   注意：沙丘语是 26 键方案，九键打不了。

四、调味道（可选）

7. 设置 → 语言与方案 → 已安装的方案 → 底部「Rime 配置文件(高级)」
   打开 dunespeak.custom.yaml，把 "dune/strength": 2 改成 1 或 3：
   1 = 只换词
   2 = 换词 + 断字 + 拟声词（默认）
   3 = 最重口吃
   保存，回上一页点「重新部署(修复)」。

五、出问题先看这里

· 提示「请补齐方案引用的文件：luna_pinyin.dict.yaml」
  导错包了——那个是电脑版方案（luna_pinyin 是电脑的词库），手机上用不了。
  把已安装的「沙丘语·Dune」停用/移除，只认准这个特供 zip 重新导入。

· 红条提示「部署失败：输入引擎没有建好会话」，连自带的「中文26键」都一直「还没生效」
  是 CyIME 引擎本身没起来，不是方案的问题。先试「重新部署(修复)」；
  还不行就：系统设置 → 应用 → CyIME → 存储 → 清除数据，
  重开 CyIME 把向导走完，再重新导入这个 zip。

· 导入时提示缺文件 / 找不到词库
  说明这台机器的雾凇词库名字对不上，把提示原文截图给我。

· 能打字但候选没味道（还是普通中文）
  方案没真正生效。回「已安装的方案」点「重新部署(修复)」，再确认当前方案是「沙丘语·Dune」。

· 九键打不出来
  切 26 键。方案编码是字母，九键的数字键位对不上。

· 想改回普通拼音
  「输入方式」里换回「雾凇拼音」就行，沙丘语方案留着不影响。

----------------------------------------
这个包和电脑版是同源的：dunespeak.schema.yaml + dunespeak.custom.yaml + lua/dune.lua。
唯一区别是电脑版挂朙月词库（luna_pinyin），这里改挂 CyIME 自带的雾凇词库（rime_ice），
简拼规则也从"引用 default.yaml 预设"改成写在本文件里。
