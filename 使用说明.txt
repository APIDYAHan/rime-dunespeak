沙丘语输入方案 · 使用说明（GitHub 正经版）
========================================

把候选词改写成《未知伤亡》（Casualties Unknown）角色 Dune（沙丘 [SAW-12]）
说话方式的 RIME 输入方案。词库来自游戏官方中文语言文件中 594 条原版台词
+ 8 则手写纸条的实测统计。

打 woele，出来的不是「我饿了」，而是——
    咯嗯... 沙—丘 饿—饿...

一、定制安装器（推荐，全新安装）
----------------------------------------
1. 到 Releases 下载 DuneSpeak-Custom-Installer-0.17.4.exe（沙丘语定制安装器）；
2. 装过旧版小狼毫的，先卸载干净；
3. 双击安装器，选好安装位置，一路「下一步」；
4. 走到「方案选单设定」窗口，第一项「沙丘语·Dune」已默认勾选，直接点「确定」
   （想同时用明月拼音、五笔，一起勾上即可）；
5. 装完按提示重启电脑，切到小狼毫就能打字。

注意：装完不要点「自动更新」，更新后大概率见不到沙丘语。


二、添加包（已经装着官方小狼毫）
----------------------------------------
1. 到 Releases 下载 DuneSpeak-Schema-AddPack.zip（沙丘语方案添加包）并解压；
2. 双击「添加沙丘语.bat」，点「添加沙丘语方案」；
3. 在弹出的官方窗口里勾「沙丘语·Dune」，点「确定」；
4. 回到向导点「检查是否添加成功」，看到「沙丘语已启用」就成了。


三、rime-install（plum，技术用户）
----------------------------------------
前置条件：已安装小狼毫（Windows，https://rime.im/）或 fcitx-rime / ibus-rime，
并且有 Git（plum 依赖 git-bash）。

    rime-install APIDYAHan/rime-dunespeak

安装完成后：
1. 右键输入法托盘图标 →「重新部署」；
2. 打开输入法设定（方案选单），把「沙丘语」加入启用列表；
3. 切换到沙丘语，开打。

注意：plum 默认不安装 lua 脚本，本包通过 recipe.yaml 显式安装 lua/dune.lua，
请勿删掉这个文件，否则沙丘语会变回普通拼音。


四、手动安装（不用 plum 的话）
----------------------------------------
1. 把 dunespeak.schema.yaml 和 dunespeak.custom.yaml 复制到 Rime 用户目录
   （Windows 默认 %APPDATA%\Rime；小狼毫安装时可自定义）；
2. 把 lua/dune.lua 复制到用户目录下的 lua\ 子目录（没有就新建）；
3. 在 default.custom.yaml 的 schema_list 里加入 - {schema: dunespeak}，
   或用「方案选单」勾选；
4. 重新部署。


五、新追加的手机方案（安卓）
----------------------------------------
手机上没有小狼毫，用的是安卓输入法方案包（Releases 里的两个 Mobile zip），
按你装的输入法二选一：

· CyIME 输入法（推荐，导入即用）
  下载 DuneSpeak-Mobile-CyIME.zip，把 zip 原样传到手机（不要解压），
  在 CyIME 里：设置 → 扩展 → 方案 → 右上角「已安装」→「导入方案」。
  详细步骤和排错见仓库「手机版/安装说明_CyIME.txt」。

· 同文输入法 Trime（已在用同文的选这个）
  下载 DuneSpeak-Mobile-Trime.zip，解压后把三个文件放进手机
  内部存储的 rime 文件夹（dune.lua 要放在 rime/lua/ 子目录里），
  再在同文里「部署」。详细步骤见「手机版/安装说明_同文Trime.txt」。

共同注意：沙丘语是 26 键方案，九键打不了；强度 1/2/3 的调法两份说明里各写了。
试打 woele，出「咯嗯... 沙—丘 饿—饿...」就是装好了。


怎么打字
----------------------------------------
· 想 打      拼音键序
· 沙—丘 饿—饿...   woele 后按空格（整句连写，中途不要按空格）
· 沙—丘 让AI 做出来   worang + AI（大写）+ 空格 + zuochulai + 空格

· 分词键是单引号 '（如 xi'an），一般用不上；
· 打整段英文可按 Shift 切西文模式；
· 换方案：Ctrl + ` 或 F4（电脑快捷键；手机在输入法的方案菜单里切）；
· 简繁切换：Ctrl + Shift + 4；
· 强度三档：编辑 dunespeak.custom.yaml 里的 dune/strength
  （1 = 只换词汇，2 = 换词 + 断字 + 拟声词【默认】，3 = 加重口吃），改完重新部署。
  手机上的改法见「五、手机」里对应的安装说明。


卸载
----------------------------------------
· 用定制安装器装的：系统设置 → 应用 → 卸载「小狼毫」，沙丘语的文件一并清掉；
· 用添加包 / rime-install / 手动装的：删除用户目录里的 dunespeak.schema.yaml、
  dunespeak.custom.yaml、lua\dune.lua，从 default.custom.yaml 移除对应条目，
  重新部署。
